# Frentista — dados públicos

Arquivos gerados automaticamente para o app Frentista. Não edite este repositório: cada publicação substitui todo o conteúdo.

| Arquivo | Conteúdo |
|---|---|
| [`data/v1/meta.json`](data/v1/meta.json) | Versão, data dos dados, total de postos e hash |
| [`data/v1/alertas.json`](data/v1/alertas.json) | Postos com registro recente de autuação da ANP por combustível fora de especificação ou bomba irregular |

Endereço: https://thiago5g.github.io/frentista-dados/data/v1/meta.json

Fonte: dados abertos da ANP (planilha de fiscalização do abastecimento e API de Revendedores). Autuação não é condenação: o estabelecimento tem direito a defesa. Este projeto não tem vínculo com a ANP nem com o governo.
